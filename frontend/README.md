# Frontend

**Trang chủ: `index.html`. Code giao diện: `src/`.**

- `src/pages`: HTML từng trang.
- `src/features`: xử lý chức năng tương ứng từng trang.
- `src/api/client.js`: gọi REST API backend.
- `src/lib`: phiên đăng nhập và hàm UI dùng chung.
- `src/app/bootstrap.js`: khởi động trang.
- `src/styles/style.css`: giao diện dùng chung.

HTML/CSS/JavaScript thuần, không cần npm build. Mở qua http://localhost:8000/app/.
