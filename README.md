# Internship Connect API

## Overview

Internship Connect is a web-based platform designed to connect university students with companies offering internship opportunities. The system provides RESTful APIs for student profile management, recruitment management, application tracking, and interview scheduling.

The platform also integrates AI-powered internship recommendations and a Retrieval-Augmented Generation (RAG) chatbot to help students discover relevant opportunities and access internship-related information.

## Main Modules

- **M03 – Student Management:** Manage student profiles, skills, CVs, and internship status.
- **M13 – Company & Internship Management:** Manage company profiles, internship listings, applications, and recruitment status.
- **M20 – Authentication & Authorization:** Implement JWT-based authentication and role-based access control.
- **AI1 – Internship Matching:** Recommend internship opportunities based on student profiles and job requirements.
- **AI2 – RAG Chatbot:** Answer internship-related questions using a knowledge base.

## Technology Stack

- **Backend:** Python, FastAPI
- **Database:** MySQL
- **API:** REST, JSON
- **Authentication:** JWT, Role-Based Access Control (RBAC)
- **AI:** Embeddings, similarity-based ranking, RAG, LLM
- **Testing:** Postman, pytest
- **Version Control:** Git, GitHub
- **Frontend:** HTML, CSS, JavaScript
