# Backend

**Code chính: `app/`. Bắt đầu từ `app/main.py`.**

- `app/core`: cấu hình, kết nối database, xác thực.
- `app/modules`: auth, students, internships, interviews, documents và ai.
- `tests`: kiểm thử, không phải code chạy ứng dụng.
- `data`: file và trạng thái sinh khi chạy, không phải source.
- `support`: tài liệu/SQL/Postman/script; có thể bỏ qua khi đọc code.

Chạy web từ gốc dự án bằng `start.ps1`.
